## Project Overview

**Name:** `roon-now-playing`
**Type:** Web application (Roon Now Playing display)
**Purpose:** Real-time album artwork and track metadata display for Roon and other music sources, on always-on screens (tablets, TVs, wall-mounted displays). Works with Roon, or in external-sources-only mode via API.

### Technology Stack

- **Framework:** Vue 3 (client, Composition API), Express 5.x (server)
- **Language:** TypeScript 5.x
- **Build System:** Vite (client), tsc (server/shared)
- **Package Manager:** pnpm 10.x (monorepo with workspaces)
- **Testing:** Vitest (unit) + Playwright (E2E / visual layout tests)
- **Linting:** ESLint (`pnpm lint`)
- **Node Version:** 20+
- **CI/CD:** GitHub Actions — Docker image publishing + a visual approval-matrix workflow on PRs

## Key Features

### Layouts (9 total)
- **detailed**: Album art + full track info + progress bar (two-column on wide screens)
- **minimal**: Full-screen artwork with overlay text (ignores background setting)
- **fullscreen**: Just the album artwork centered, no text
- **ambient**: Color-extracted background with artwork and info (10-ft UI)
- **cover**: Clean album art with crossfade transitions and shadow
- **facts-columns**: Two-column artwork + AI-generated facts
- **facts-overlay**: Full artwork background with facts overlaid at the bottom
- **facts-carousel**: Blurred artwork background with rotating AI facts
- **basic**: Legacy-compatible layout for older browsers (iOS 12+); avoids modern CSS

### Backgrounds (14 options)
`black`, `white`, `dominant`, `gradient-radial`, `gradient-linear`, `gradient-linear-multi`,
`gradient-radial-corner`, `gradient-mesh`, `blur-subtle`, `blur-heavy`, `duotone`,
`posterized`, `gradient-noise`, `blur-grain`. Most are derived from album-artwork color
extraction. The `minimal` layout ignores the background (artwork covers the screen).
Canonical list: `BACKGROUNDS` in `packages/shared/src/index.ts`.

### Fonts (17 options)
`system` (default) plus 16 Google fonts (Patua One, Comfortaa, Inter, Roboto, Montserrat, …).
Canonical list: `FONTS` in `packages/shared/src/index.ts`.

### AI Facts
Facts layouts generate lesser-known facts about the playing track via a configurable LLM
provider: **Anthropic, OpenAI, OpenRouter, or a local OpenAI-compatible server (Ollama/LM
Studio)**. Provider/model/prompt configured in the Admin panel; API keys via Admin or env
vars (`ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `OPENROUTER_API_KEY`, `LOCAL_LLM_URL`). Provider
implementations live in `packages/server/src/llm.ts`; the model lists are in
`packages/shared/src/index.ts` (`LLM_MODELS`).

### Configurable Options (URL params + Admin UI + localStorage; server-authoritative)
- `layout`, `font`, `background`, `zone` (URL params + per-screen admin push)
- Font scale and artwork scale (global + per-screen overrides)
- Enabled layouts (which layouts participate in tap-to-cycle, per screen)
- Settings are persisted server-side per device (`clientSettings.ts`) and pushed to displays
  on connect, so configuration survives reloads and is authoritative across clients.

### Admin Panel & Onboarding
- `/admin` — lists connected clients, pushes settings remotely, manages friendly names,
  configures AI facts (provider/model/key), and global display settings.
- Self-service onboarding: new displays auto-generate a friendly name and show a QR code
  linking to a per-screen config page (`/admin/screen/:name`).
- Roon-optional: `ROON_ENABLED=false` runs in external-sources-only mode.

## Architecture Decisions

| Decision | Reasoning |
|----------|-----------|
| Monorepo with pnpm workspaces | Share types between client/server |
| Vue 3 Composition API | Better TypeScript support, composables pattern |
| Color extraction from artwork | Dynamic theming / gradient backgrounds |
| Roon optional (nullable RoonClient) | Support non-Roon sources via the external-sources API |
| Server-authoritative client config | Settings persist per device and are pushed on connect |
| AI facts via pluggable LLM providers | Anthropic/OpenAI/OpenRouter/local, swappable in Admin |
| Adaptive text contrast (WCAG) | Keep text readable over arbitrary artwork-derived backgrounds |
| Fluid type scale (clamp + container units) | Scale typography from tablets to 4K; `basic` keeps a fixed fallback for legacy browsers |
| Visual approval matrix (Playwright) | Review every layout × background at the approved resolutions |

## Key Composables

| Composable | Purpose |
|------------|---------|
| `useColorExtraction` | Extract palette + vibrant gradient from artwork |
| `useBackgroundStyle` | Generate CSS for all background types |
| `usePreferences` | URL params, localStorage, preference persistence |
| `useWebSocket` | WebSocket connection + metadata sync |
| `useNowPlaying` | Derive now-playing state + artwork URL |
| `useFacts` | Fetch/rotate AI facts for the current track |

## Testing & Visual Review

- **Unit:** Vitest (`pnpm test`).
- **E2E / visual:** Playwright (`pnpm test:e2e`). The **approval matrix** (`pnpm
  test:e2e:matrix`) renders every layout × background at the approved review resolutions
  (iPad-landscape, TV-1080p, TV-4K). `pnpm run review:gallery` builds an interactive
  flag-for-review gallery; `pnpm run review:pack` builds contact sheets. A GitHub Actions
  workflow uploads these as PR artifacts. See `.ai-assistant/` + README "Visual testing".

## Important Technical Notes

### Express 5.x Route Patterns
Express 5 uses path-to-regexp v8+ which requires **named wildcard parameters**.
- **Wrong:** `app.get('*', ...)` — throws "Missing parameter name"
- **Correct:** `app.get('*splat', ...)`

### Runtime state / DATA_DIR
Server runtime state lives in `packages/server/config/` (`DATA_DIR`, default `./config`):
Roon pairing tokens (`roonstate.json`), client names, display settings, facts config. These
are gitignored (`*.json`); `*.example.json` templates are committed.

### Docker CI/CD
- `.github/workflows/docker-publish.yml` builds multi-platform images (amd64, arm64) to
  `ghcr.io/arthursoares/roon-now-playing`; triggered on push to main or version tags (`v*`).
